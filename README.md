# 单文件markdown角色扮演系统

## 本提示词有什么用

1. 去除模型对话中八股文、模板化等明显 AI 语气。
2. 搭建角色扮演框架，优化角色扮演体验。
3. 进行小说、剧本等创意写作。
4. 提供多种写作风格，满足不同创作需求。

## 使用方法

- 各AI网页端：点击加号上传对应markdown文件，在输入框输入：“进入角色扮演模式”即可，模型将提示用户补全相关信息。
- cherry studio/Chatbox/rikkahub/各种harness等：直接使用文件上传或者设置为预设/前置提示词注入，在输入框输入：“进入角色扮演模式”，即可让模型配合你开始角色扮演工作。

## 效果较好模型

- DeepSeek V4 Pro 0813
- DeepSeek V4 Flash 0731
- DeepSeek V3.2
- Kimi K3
- Kimi K2.6
- GLM 5
- GLM 4.7

### 除此之外

- **不稳定**：DeepSeek V4.1 Flash 上效果看模型心情，要做好迎接它神鬼二象性的心理准备。
- **不推荐**：GLM 5.3 Flash（代码特化。模型自身创作能力严重不足）
- Mimo、Grok、Gemini、GPT、Claude等等，个人能力有限未能逐一详细测试，期待大伙使用反馈。
